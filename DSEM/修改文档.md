# 学生公寓电费信息管理系统 - 修改文档

## 项目概述

本项目基于微信小程序 + Spring Boot 实现了一个完整的学生公寓电费信息管理系统。

## 主要优化点

### 1. 数据库设计优化

#### 原设计问题：
- 原设计使用多张表分别存储学生、公寓管理员、系统管理员
- 表结构重复，维护困难

#### 优化方案：
- **统一用户表**：使用 `sys_user` 表统一管理所有用户（学生、公寓管理员、系统管理员）
- **角色字段区分**：使用 `role` 字段区分不同角色（0-学生，1-公寓管理员，2-系统管理员）
- **添加通用字段**：增加 `create_time`、`update_time`、`deleted` 等通用字段，支持逻辑删除

### 2. 技术栈升级

#### 原设计：
- Spring Boot 2.7.x
- 自定义 JWT 工具类

#### 优化后：
- **Spring Boot 3.2.x**：使用最新稳定版本，支持 Java 17
- **Spring Security + JWT**：使用 Spring Security 框架，更安全规范
- **MyBatis Plus 3.5.5**：使用 Spring Boot 3 兼容版本
- **JJWT 0.12.3**：使用最新版 JWT 库

### 3. 功能简化

#### 缴费流程优化：
- **原流程**：学生缴费 → 生成账单 → 管理员确认 → 完成
- **优化后**：学生缴费 → 自动确认 → 完成
- **说明**：简化了缴费流程，缴费后自动更新用电记录状态，无需管理员手动确认每笔缴费

#### 报修状态简化：
- **原状态**：待处理、已通过、已驳回、已完成
- **优化后**：待处理、处理中、已完成
- **说明**：简化了报修流程，更符合实际使用场景

### 4. API 接口调整

#### 优化内容：
1. **统一响应格式**：所有接口返回统一格式的 JSON 数据
   ```json
   {
     "code": 200,
     "message": "success",
     "data": {}
   }
   ```

2. **RESTful 风格**：接口路径更加规范
   - 用户相关：`/api/user/*`
   - 电费相关：`/api/electricity/*`
   - 缴费相关：`/api/payment/*`
   - 报修相关：`/api/repair/*`
   - 公告相关：`/api/announcement/*`
   - 管理相关：`/api/admin/*`

3. **JWT 认证**：使用 Bearer Token 方式进行身份认证

### 5. 安全性增强

#### 优化措施：
1. **密码加密**：使用 BCrypt 加密存储用户密码
2. **JWT Token**：使用 JWT 进行身份认证，Token 有效期 24 小时
3. **接口权限控制**：通过 JWT Filter 对所有接口进行认证检查
4. **跨域支持**：配置 CORS 支持微信小程序访问

### 6. 前端优化

#### 微信小程序端：
1. **统一请求封装**：封装 `request.js` 统一处理请求和响应
2. **Token 自动处理**：自动携带 Token，过期自动跳转登录页
3. **UI 设计**：使用卡片式设计，界面简洁美观
4. **状态管理**：使用全局数据管理用户信息和 Token

| id_card | VARCHAR(18) | 身份证号 |

## 启动说明

### 后端启动
1. 创建 MySQL 数据库 `electrical_db`
2. 执行 `schema.sql` 初始化数据库
3. 修改 `application.yml` 中的数据库连接配置
4. 运行 `ElectricalManagementApplication`

### 前端启动
1. 使用微信开发者工具打开 `electrical-miniapp` 文件夹
2. 在开发者工具中配置不校验合法域名（开发环境）
3. 编译运行
