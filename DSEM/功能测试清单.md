## 四、常见问题排查

### 问题1：403 错误
**原因**：Spring Security 拦截了请求，但 JWT 过滤器没有正确处理
**解决**：
- 检查后端是否正确启动
- 检查 SecurityConfig 是否正确配置 JWT 过滤器
- 检查 JwtAuthenticationFilter 是否正确设置 SecurityContext

### 问题2：401 错误
**原因**：Token 无效或过期
**解决**：
- 检查请求头是否携带 `Authorization: Bearer {token}`
- 检查 token 是否正确存储在本地
- 重新登录获取新 token

### 问题3：注册页面楼层列表为空
**原因**：`/api/admin/floor/list` 接口被拦截
**解决**：
- 检查白名单配置是否包含该接口
- 检查 SecurityConfig 和 JwtAuthenticationFilter 白名单是否一致

## 六、接口清单

### 白名单接口（无需登录）
| 接口 | 方法 | 说明 |
|------|------|------|
| /api/user/login | POST | 登录 |
| /api/user/register | POST | 注册 |
| /api/admin/floor/list | GET | 获取楼层列表 |
| /api/announcement/list | GET | 获取公告列表 |

### 需要登录的接口
| 接口 | 方法 | 说明 |
|------|------|------|
| /api/user/info | GET | 获取用户信息 |
| /api/user/update | PUT | 更新用户信息 |
| /api/user/password | PUT | 修改密码 |
| /api/electricity/list | GET | 用电记录列表 |
| /api/electricity/balance | GET | 电费余额 |
| /api/electricity/unpaid | GET | 未缴费列表 |
| /api/payment/bill/list | GET | 缴费账单列表 |
| /api/payment/pay | POST | 支付账单 |
| /api/repair/add | POST | 提交报修 |
| /api/repair/list | GET | 我的报修列表 |
