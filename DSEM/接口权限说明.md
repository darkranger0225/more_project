# 学生公寓电费信息管理系统 - 接口权限说明

## 白名单接口（无需登录）

以下接口可以在未登录状态下访问：

| 接口路径 | HTTP方法 | 说明 |
|---------|---------|------|
| `/api/user/login` | POST | 用户登录 |
| `/api/user/register` | POST | 用户注册 |
| `/api/admin/floor/list` | GET | 获取楼层列表（注册页面使用） |
| `/api/announcement/list` | GET | 获取公告列表（首页展示） |

## 配置说明

### SecurityConfig.java
配置 Spring Security 的授权规则，定义哪些接口可以匿名访问。

### JwtAuthenticationFilter.java
JWT 过滤器，拦截所有请求并验证 Token（白名单接口除外）。

**注意**：两个配置文件中的白名单必须保持一致！

## 修改白名单

如果需要添加新的免登录接口，需要同时修改以下两个文件：

1. `SecurityConfig.java` - 在 `authorizeHttpRequests` 中添加 `.requestMatchers("/api/xxx/xxx").permitAll()`
2. `JwtAuthenticationFilter.java` - 在 `WHITE_LIST` 列表中添加 `"/api/xxx/xxx"`

## 请求头格式

需要登录的接口，请求头必须包含：
```
Authorization: Bearer {JWT_TOKEN}
```

例如：
```
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9.xxx.xxx
```
